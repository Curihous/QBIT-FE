## 요구사항
- Flutter SDK (3.8.0 이상)
- Dart SDK
- iOS: Xcode, CocoaPods
- Android: Android Studio, Android SDK

## 개발 가이드

### 초기 설정
```bash
# 의존성 설치
flutter pub get
```
### 실행
```bash
# iOS 실행
flutter run -d [iOS 디바이스 ID]

# Android 실행
flutter run -d [Android 디바이스 ID]

# 핫 리로드 개발
flutter run --hot
```
